About this application (16 languages)

[intro] # Rental Catalog — what this application does Rental Catalog maintains a MongoDB catalogue of equipment offered for rent or sale. Each equipment record has a unique part number, a name, descriptions, quantity, rental prices for different periods, booking and publication flags, and references to images or documents. The List and Editor fields can be configured without changing the Python source. Publishing produces a responsive, searchable HTML catalogue with images and rental prices. Begin with Config to set the MongoDB connection, the folder for media files, and the published HTML destination. Use List to browse or search existing records, Editor to create or update equipment details, and Publishing to produce the catalogue. Fields controls which columns and inputs appear in the List and Editor. Important database records and media files should be backed up separately before large edits or publication updates. [tab:list] # List List shows equipment records from the configured MongoDB database and collection. The Search box matches part number, short name, long description and detailed description without regard to letter case. New opens a new record in Editor, while Refresh reloads the current results. Selecting a record in the list loads its details into Editor. By default, the columns show Part, Name, Qty, 3 Day, Weekly, Monthly, Book and Don't Publish. The Fields tab defines column names, widths, alignment and order. Page Size in Config limits the maximum number of matching records shown; the footer reports the loaded count and the total match count. [tab:editor] # Editor Editor creates and updates equipment records. Search passes the entered text to List. New clears the form, generates a candidate part number, sets quantity to 1 and selects the three-day price as the default. Add inserts a new MongoDB record. Update changes the selected record; select an item from List before using Update. Each part number must contain exactly two letters followed by two digits, such as AB12, and must be unique. The default form contains Part Number, Short Name, Long Description, Detailed Description, Quantity, Daily Price, 3 Day Price, Weekly Price, Monthly Price, Default Price, Don't Publish, Book, Primary Image and Document. Money values are stored numerically, quantity is stored as an integer, and the two flags are Boolean fields. Default Price chooses among daily, three-day, weekly and monthly periods. The Fields tab controls which editor inputs are displayed. The Media area previews the primary image. Pick Image copies an image from the file system into the configured Media Directory. Paste Image imports an image from the clipboard when Pillow support is available. Dragging an image into the preview is supported when tkinterdnd2 is installed. Pick Document copies a selected file into the Media Directory and places its filename in the Document field. Imported files use the part number in their filenames; a numbered suffix avoids overwriting an existing file. Images are stored as files and referenced by name in the MongoDB record. Use Add or Update to save changed record details and media references. [tab:publishing] # Publishing Publishing generates a responsive single-page HTML rental catalogue. The list shows equipment records loaded by the current List search and page limit. Refresh reloads the available entries. Select Highlighted marks highlighted records; Select All marks all currently displayed records; Clear Selection removes the marks. Double-clicking selected rows toggles their publication selection. Publish Selection writes marked records, whereas Publish All queries the full collection. In both cases, records with Don't Publish enabled are excluded. The published items are ordered by part number. The output is written to the configured Publish HTML File, or a destination is requested when none has been set. Current images are copied into a companion media folder beside the HTML file, when the referenced files are available. The published page provides equipment cards, images, names, descriptions, booking status and price information. Visitors can search by part number or description, choose a price period, and sort by part number, name, description, or ascending or descending price. Price periods are Daily, 3 Day, Weekly and Monthly. The displayed currency symbol comes from Config. When a selected period has no nonzero price, the page displays Ask for price. Publishing writes to the selected HTML output path and may replace an existing HTML file. Confirm that the destination and intended catalogue selection are correct before publishing. Keep the companion media folder with the HTML file when moving the published site. [tab:fields] # Fields Fields has two subtabs: Tree View Fields and Editor Fields. Tree View Fields controls the List columns and their display order. For each column, enter its field name, label, width and alignment, and set Index or Unique metadata if required. Add / Apply creates or updates the field definition; Remove deletes it from the configured list; Up and Down change its order. Changing the list definition rebuilds the displayed List. Editor Fields controls the record input form. A field definition includes its name, label, type, line count, length, Index and Unique metadata. The supported editor type codes are 1 Short, 2 Long, 3 Text, 4 Integer, 5 Money, 6 Boolean, 7 Price Type and 8 Media. Multiline text, checkboxes and the price-period selector are displayed according to field type. Use Add / Apply, Remove, Up and Down to manage the form order and definitions. Definitions are saved in rental_catalog.json. Changing or removing a field from the interface does not by itself delete that field from existing MongoDB documents. The application also attempts to create a unique index on part_number when connecting to the collection. Review existing data before changing key fields or their definitions. [tab:config] # Config Mongo URI, Database and Collection define the MongoDB data source. The defaults are localhost, rental and catalog. Page Size controls the maximum number of records loaded in List. Media Directory is the folder used for imported images and documents; use Browse to select it. Publish HTML File specifies the generated catalogue destination, and Currency Symbol sets the prefix shown with published prices. Connect + Refresh reconnects to the specified MongoDB database and reloads records. Save Config writes settings to rental_catalog.json beside the application source. The application also saves the selected main tab, selected Fields subtab, most recently selected record, appearance settings and window dimensions. MongoDB document content and physical media files are separate from this configuration file. The media directory must be set before importing images or documents. Publishing copies referenced images from that directory when they exist; it does not embed original image content in MongoDB. Ensure the database, media directory and HTML output paths are backed up as appropriate. [tab:ui-choices] # UI Choices UI Choices uses the shared interface component to select appearance options, including theme and display density. Changes are saved to application configuration. The initial theme is Graphite and density is Normal. If the shared component is unavailable, the tab displays an explanatory message. [tab:gateway] # Gateway Gateway integrates the shared application controller when GatewayController is available. It provides access to the common application launcher independently of the rental catalogue records. If the controller cannot be loaded, the tab displays an unavailable message.

[intro] # كتالوج التأجير — وظيفة هذا التطبيق يدير Rental Catalog كتالوج المعدات المعروضة للتأجير أو البيع داخل MongoDB. يحتوي كل سجل على رقم قطعة فريد واسم وأوصاف وكمية وأسعار تأجير لفترات مختلفة وعلامات للحجز والنشر ومراجع للصور أو المستندات. يمكن تهيئة حقول List وEditor دون تعديل الشيفرة المصدرية بلغة Python. تنشئ Publishing كتالوج HTML متجاوباً وقابلاً للبحث يحتوي على الصور وأسعار التأجير. ابدأ من Config لتحديد اتصال MongoDB ومجلد ملفات الوسائط ووجهة ملف HTML المنشور. استخدم List لاستعراض السجلات الحالية أو البحث فيها، وEditor لإنشاء تفاصيل المعدات أو تحديثها، وPublishing لإنشاء الكتالوج. تتحكم Fields في الأعمدة وحقول الإدخال التي تظهر في List وEditor. احفظ نسخاً احتياطية منفصلة من سجلات قاعدة البيانات المهمة وملفات الوسائط قبل إجراء تعديلات كبيرة أو تحديثات للنشر. [tab:list] # القائمة تعرض List سجلات المعدات من قاعدة بيانات MongoDB والمجموعة المحددتين في الإعدادات. يبحث مربع Search في رقم القطعة والاسم المختصر والوصف الطويل والوصف التفصيلي دون التمييز بين الأحرف الكبيرة والصغيرة. يفتح New سجلاً جديداً في Editor، بينما يعيد Refresh تحميل النتائج الحالية. يؤدي تحديد سجل في القائمة إلى تحميل تفاصيله في Editor. الأعمدة الافتراضية هي Part وName وQty و3 Day وWeekly وMonthly وBook وDon't Publish. تحدد علامة التبويب Fields أسماء الأعمدة وعرضها ومحاذاتها وترتيبها. يحدد Page Size في Config الحد الأقصى لعدد السجلات المطابقة المعروضة، ويعرض التذييل عدد السجلات المحملة وإجمالي النتائج المطابقة. [tab:editor] # المحرر يُنشئ Editor سجلات المعدات ويحدّثها. يمرر Search النص المدخل إلى List. يمسح New النموذج وينشئ اقتراحاً لرقم القطعة ويضبط الكمية على 1 ويختار سعر ثلاثة أيام افتراضياً. يضيف Add سجلاً جديداً إلى MongoDB. يغيّر Update السجل المحدد؛ اختر عنصراً من List أولاً. يجب أن يتكون كل رقم قطعة من حرفين بالضبط يتبعهما رقمان، مثل AB12، وأن يكون فريداً. يضم النموذج الافتراضي Part Number وShort Name وLong Description وDetailed Description وQuantity وDaily Price و3 Day Price وWeekly Price وMonthly Price وDefault Price وDon't Publish وBook وPrimary Image وDocument. تُخزن المبالغ كقيم رقمية والكمية كعدد صحيح والعلامتان كقيم منطقية Boolean. يختار Default Price فترة يومية أو ثلاثة أيام أو أسبوعية أو شهرية. تحدد Fields مدخلات Editor التي تظهر للمستخدم. تعرض منطقة Media معاينة للصورة الرئيسية. ينسخ Pick Image صورة من نظام الملفات إلى Media Directory. يستورد Paste Image صورة من الحافظة عند توفر Pillow. يمكن سحب صورة إلى المعاينة إذا كانت مكتبة tkinterdnd2 مثبتة. ينسخ Pick Document الملف المحدد إلى Media Directory ويضع اسمه في حقل Document. تتضمن أسماء الملفات المستوردة رقم القطعة، وتمنع لاحقة مرقمة الكتابة فوق ملف موجود. تُحفظ الصور كملفات منفصلة ويُشار إليها بالاسم داخل سجل MongoDB. استخدم Add أو Update لحفظ التغييرات ومراجع الوسائط. [tab:publishing] # النشر تنشئ Publishing كتالوج تأجير HTML متجاوباً في صفحة واحدة. تعرض القائمة السجلات المحملة وفق البحث الحالي في List وحد الصفحات. يعيد Refresh تحميل العناصر. يضع Select Highlighted علامة على السجلات المظللة، ويحدد Select All جميع السجلات الظاهرة، بينما يزيل Clear Selection العلامات. يؤدي النقر المزدوج على الصفوف المحددة إلى تبديل اختيارها للنشر. يكتب Publish Selection السجلات المحددة، بينما يستعلم Publish All عن المجموعة بأكملها. تُستبعد في الحالتين السجلات التي فُعّل فيها Don't Publish. تُرتب العناصر المنشورة حسب رقم القطعة. يُحفظ الناتج في Publish HTML File المحدد، أو يُطلب اختيار وجهة إذا لم تُحدد. تُنسخ الصور المرجعية المتوفرة إلى مجلد وسائط مرافق بجانب ملف HTML. تعرض الصفحة المنشورة بطاقات المعدات وصورها وأسماءها وأوصافها وحالة الحجز والأسعار. يستطيع الزائر البحث برقم القطعة أو الوصف، واختيار فترة السعر، والفرز برقم القطعة أو الاسم أو الوصف أو السعر تصاعدياً أو تنازلياً. الفترات هي Daily و3 Day وWeekly وMonthly. يُؤخذ رمز العملة من Config. إذا لم يكن هناك سعر غير صفري للفترة المختارة، تظهر عبارة Ask for price. تكتب Publishing إلى مسار HTML المختار وقد تستبدل ملف HTML موجوداً. تحقق من الوجهة والعناصر المطلوبة قبل النشر. عند نقل الموقع المنشور، احتفظ بمجلد الوسائط المرافق مع ملف HTML. [tab:fields] # الحقول تحتوي Fields على علامتي تبويب فرعيتين: Tree View Fields وEditor Fields. تتحكم Tree View Fields في أعمدة List وترتيب عرضها. أدخل اسم الحقل وتسميته وعرضه ومحاذاته لكل عمود، واضبط بيانات Index أو Unique عند الحاجة. ينشئ Add / Apply التعريف أو يحدّثه، ويزيله Remove من القائمة المضبوطة، ويغير Up وDown ترتيبه. يؤدي تعديل التعريفات إلى إعادة بناء List المعروضة. تتحكم Editor Fields في نموذج إدخال السجلات. يشمل تعريف الحقل اسمه وتسميته ونوعه وعدد الأسطر وطوله وبيانات Index وUnique. رموز الأنواع المدعومة هي 1 Short و2 Long و3 Text و4 Integer و5 Money و6 Boolean و7 Price Type و8 Media. تظهر النصوص متعددة الأسطر ومربعات الاختيار ومحدد فترة السعر وفق نوع الحقل. استخدم Add / Apply وRemove وUp وDown لإدارة التعريفات وترتيبها. تُحفظ التعريفات في rental_catalog.json. لا يؤدي تعديل حقل أو حذفه من الواجهة إلى حذفه تلقائياً من مستندات MongoDB الموجودة. يحاول التطبيق أيضاً إنشاء فهرس فريد على part_number عند الاتصال بالمجموعة. راجع البيانات الحالية قبل تعديل الحقول الأساسية أو تعريفاتها. [tab:config] # الإعدادات تحدد Mongo URI وDatabase وCollection مصدر بيانات MongoDB. القيم الافتراضية هي localhost وrental وcatalog. يتحكم Page Size في الحد الأقصى للسجلات التي تُحمّل في List. يشير Media Directory إلى مجلد الصور والمستندات المستوردة؛ استخدم Browse لاختياره. يحدد Publish HTML File وجهة الكتالوج الناتج، ويضبط Currency Symbol رمز العملة الذي يسبق الأسعار المنشورة. يعيد Connect + Refresh الاتصال بقاعدة بيانات MongoDB المحددة ويحمل السجلات من جديد. يكتب Save Config الإعدادات إلى rental_catalog.json بجانب مصدر التطبيق. يحفظ التطبيق أيضاً علامة التبويب الرئيسية المختارة وعلامة Fields الفرعية وآخر سجل محدد وتفضيلات المظهر وأبعاد النافذة. تبقى مستندات MongoDB وملفات الوسائط الفعلية منفصلة عن ملف الإعدادات هذا. يجب تحديد Media Directory قبل استيراد الصور أو المستندات. تنسخ Publishing الصور المشار إليها من المجلد عند وجودها، ولا تدمج محتوى الصور الأصلي داخل MongoDB. احتفظ بنسخ احتياطية مناسبة من قاعدة البيانات ومجلد الوسائط ومسارات إخراج HTML. [tab:ui-choices] # خيارات الواجهة تستخدم UI Choices مكون الواجهة المشترك لاختيار المظهر، بما في ذلك السمة وكثافة العرض. تُحفظ التغييرات في إعدادات التطبيق. السمة الأولية هي Graphite والكثافة Normal. إذا لم يتوفر المكون المشترك، تعرض علامة التبويب رسالة توضيحية. [tab:gateway] # Gateway يدمج Gateway وحدة التحكم المشتركة بالتطبيقات عندما يكون GatewayController متوفراً. يوفر الوصول إلى مشغل التطبيقات العام بصورة مستقلة عن سجلات كتالوج التأجير. إذا تعذر تحميل وحدة التحكم، تظهر رسالة تفيد بعدم توفرها.

[intro] # Katalogo sa pag-abang — unsay gibuhat sa aplikasyon Ang Rental Catalog nagdumala sa katalogo sa mga kagamitan nga paabangan o ibaligya gamit ang MongoDB. Ang matag rekord adunay talagsaong numero sa piyesa, ngalan, mga paghulagway, gidaghanon, presyo sa abang alang sa lain-laing panahon, mga timaan sa pagpareserba ug pagmantala, ug mga reperensiya sa hulagway o dokumento. Sugdi sa Config aron itakda ang koneksiyon sa MongoDB, folder sa media file ug destinasyon sa gipublikang HTML. Paghimo og lahi nga backup sa importante nga rekord sa database ug sa media file sa dili pa maghimo og dagkong kausaban o mag-update sa publikasyon. エディター Editor は機器レコードを作成・更新します。Search は入力した文字列を List に渡します。New はフォームを消去し、部品番号の候補を生成し、数量を 1 にして 3 日間料金を標準にします。Add は MongoDB に新規レコードを挿入します。Update は選択したレコードを変更するため、先に List で対象を選択してください。 部品番号は AB12 のように、ちょうど 2 文字の英字に 2 桁の数字を続けた一意の値でなければなりません。標準フォームには Part Number、Short Name、Long Description、Detailed Description、Quantity、Daily Price、3 Day Price、Weekly Price、Monthly Price、Default Price、Don't Publish、Book、Primary Image、Document が含まれます。金額は数値、数量は整数、二つのフラグは真偽値として保存します。Default Price は日単位、3 日間、週単位、月単位から選びます。Fields で Editor の入力項目を管理します。 Media 領域は主画像をプレビューします。Pick Image はファイルシステムから画像を Media Directory にコピーします。Pillow が利用可能なら Paste Image でクリップボードの画像を取り込めます。tkinterdnd2 がインストールされていれば、プレビューへのドラッグもできます。Pick Document は選択したファイルを Media Directory にコピーし、ファイル名を Document に設定します。取り込むファイル名には部品番号を使用し、既存のファイルを上書きしないよう番号の接尾辞を追加します。画像はファイルとして保存され、MongoDB レコードではファイル名で参照します。変更とメディア参照は Add または Update で保存してください。 [tab:publishing] # 公開 Publishing は、レスポンシブな 1 ページの HTML レンタルカタログを生成します。一覧には現在の List 検索とページ件数制限で読み込んだ機器が表示されます。Refresh は一覧を再読み込みします。Select Highlighted は強調行、Select All は表示中の全行を選択し、Clear Selection は選択を解除します。選択行をダブルクリックすると公開対象の選択状態が切り替わります。 Publish Selection は選択したレコードを書き出し、Publish All はコレクション全体を照会します。どちらの場合も Don't Publish が有効なレコードは除外します。公開項目は部品番号順です。出力は設定済みの Publish HTML File に保存され、未設定なら保存先を尋ねます。参照画像が存在する場合は、HTML ファイルの横にある付属メディアフォルダーへコピーされます。 公開ページには機器カード、画像、名称、説明、予約状況、価格が表示されます。訪問者は部品番号または説明で検索し、料金期間を選び、部品番号・名称・説明・価格の昇順または降順で並べ替えられます。期間は Daily、3 Day、Weekly、Monthly です。通貨記号は Config で設定します。選んだ期間にゼロ以外の価格がないときは Ask for price と表示します。 Publishing は指定された HTML パスに書き込み、既存の HTML ファイルを置き換える場合があります。公開前に保存先と公開対象を確認してください。公開済みサイトを移動するときは、HTML ファイルと付属メディアフォルダーを一緒に移動してください。 [tab:fields] # フィールド Fields には Tree View Fields と Editor Fields という二つのサブタブがあります。Tree View Fields は List の列と表示順を管理します。各列のフィールド名、ラベル、幅、配置を入力し、必要に応じて Index または Unique のメタデータを設定します。Add / Apply は定義を追加・更新し、Remove は設定済み一覧から削除し、Up と Down は順序を変更します。定義を変更すると表示中の List が再構築されます。 Editor Fields は入力フォームを管理します。定義には名称、ラベル、種類、行数、長さ、Index、Unique が含まれます。利用可能な種類コードは 1 Short、2 Long、3 Text、4 Integer、5 Money、6 Boolean、7 Price Type、8 Media です。複数行テキスト、チェックボックス、料金期間の選択は種類に応じて表示されます。Add / Apply、Remove、Up、Down で定義と順序を管理してください。 定義は rental_catalog.json に保存されます。画面上でフィールドを変更・削除しても、既存の MongoDB 文書からは自動的に削除されません。コレクション接続時には part_number に一意のインデックスを作成することも試みます。重要なフィールドや定義を変更する前に既存のデータを確認してください。 [tab:config] # 設定 Mongo URI、Database、Collection で MongoDB の接続先を定義します。標準値は localhost、rental、catalog です。Page Size は List に読み込むレコードの最大数です。Media Directory は取り込んだ画像や文書のフォルダーで、Browse から選択します。Publish HTML File は生成カタログの保存先、Currency Symbol は公開価格の通貨記号です。 Connect + Refresh は指定された MongoDB に再接続してレコードを再読み込みします。Save Config はソースファイルと同じ場所の rental_catalog.json に設定を書き込みます。メインタブ、Fields サブタブ、最後に選択したレコード、外観設定、ウィンドウのサイズも保存します。MongoDB の文書と実際のメディアファイルは、この設定ファイルとは別です。 画像や文書を取り込む前に Media Directory を設定してください。Publishing は参照先の画像が存在するときにそのフォルダーからコピーしますが、元画像の内容を MongoDB に埋め込みません。必要に応じてデータベース、メディアフォルダー、HTML 出力先をバックアップしてください。 [tab:ui-choices] # 画面表示の選択 UI Choices は共通インターフェース部品でテーマや表示密度などを設定します。変更はアプリケーション設定に保存されます。初期テーマは Graphite、密度は Normal です。共通部品が利用できない場合は説明が表示されます。 [tab:gateway] # Gateway GatewayController が利用可能な場合、Gateway は共通のアプリケーション管理機能を統合します。レンタルカタログのレコードとは独立して共通のアプリ起動機能を使えます。読み込みに失敗した場合は利用不可のメッセージが表示されます。

List와 Editor의 필드는 Python 소스 코드를 변경하지 않고 설정할 수 있습니다. Publishing은 이미지와 요금이 포함된 반응형 검색 가능 HTML 목록을 생성합니다. 먼저 Config에서 MongoDB 연결, 미디어 파일 폴더와 게시할 HTML 위치를 지정합니다. List에서는 기존 기록을 검색하고 탐색하며, Editor에서는 장비 정보를 만들거나 수정하고, Publishing에서는 목록을 생성합니다. Fields는 List와 Editor에 표시할 열과 입력 항목을 제어합니다. 대규모 수정이나 게시 내용 변경 전에 중요한 데이터베이스 기록과 미디어 파일을 각각 백업하십시오. New는 Editor에서 새 기록을 열고 Refresh는 현재 결과를 다시 불러옵니다. 목록의 기록을 선택하면 해당 세부 정보가 Editor에 표시됩니다. 기본 열은 Part, Name, Qty, 3 Day, Weekly, Monthly, Book, Don't Publish입니다. Fields 탭에서 열 이름, 너비, 정렬 방식과 순서를 지정합니다. Config의 Page Size는 표시할 일치 기록의 최대 수를 제한합니다. 아래쪽에는 불러온 기록 수와 전체 일치 수가 표시됩니다. [tab:editor] # 편집기 Editor는 장비 기록을 만들고 갱신합니다. Search는 입력한 문장을 List로 전달합니다. New는 양식을 지우고 후보 부품 번호를 생성하며 수량을 1로 설정하고 3일 요금을 기본으로 선택합니다. Add는 MongoDB에 새 기록을 추가합니다. Update는 선택된 기록을 변경하므로 먼저 List에서 항목을 선택해야 합니다. 부품 번호는 AB12처럼 정확히 두 글자 뒤에 숫자 두 개가 오고 중복되지 않아야 합니다. 기본 양식에는 Part Number, Short Name, Long Description, Detailed Description, Quantity, Daily Price, 3 Day Price, Weekly Price, Monthly Price, Default Price, Don't Publish, Book, Primary Image, Document가 있습니다. 금액은 숫자, 수량은 정수, 두 표시 항목은 불리언으로 저장됩니다. Default Price는 일일, 3일, 주간, 월간 기간 중 하나를 선택합니다. Fields에서 Editor의 표시 항목을 조정합니다. Media 영역에서는 기본 이미지를 미리 볼 수 있습니다. Pick Image는 파일 시스템의 이미지를 Media Directory로 복사합니다. [tab:publishing] # 게시 Publishing은 반응형 단일 페이지 HTML 대여 목록을 만듭니다. 목록에는 현재 List 검색과 페이지 제한에 따라 불러온 장비 기록이 표시됩니다. Refresh는 항목을 다시 불러옵니다. Select Highlighted는 강조된 기록을, Select All은 표시된 모든 기록을 선택하고 Clear Selection은 선택 표시를 지웁니다. 선택한 행을 두 번 클릭하면 게시 선택 상태가 전환됩니다. Денежные значения хранятся в числовом формате, количество — как целое число, а два признака — как логические значения. Default Price выбирает суточный, трёхдневный, недельный или месячный период. Fields управляет видимостью полей Editor. В области Media отображается основное изображение. Pick Image копирует изображение из файловой системы в Media Directory. Paste Image импортирует изображение из буфера обмена при наличии Pillow. При установленном tkinterdnd2 изображение можно перетащить в область просмотра. Pick Document копирует выбранный файл в Media Directory и записывает его имя в Document. Имена импортированных файлов содержат номер изделия; числовой суффикс предотвращает перезапись существующих файлов. Изображения хранятся как файлы, а записи MongoDB ссылаются на них по имени. Используйте Add или Update для сохранения изменений и ссылок на медиафайлы. [tab:publishing] # Публикация Publishing создаёт адаптивный одностраничный HTML-каталог аренды. Список содержит записи, загруженные текущим поиском List и ограничением размера страницы. Refresh обновляет записи. Select Highlighted отмечает выделенные строки, Select All — все отображаемые, Clear Selection — снимает отметки. Двойной щелчок по выбранной строке переключает её выбор для публикации. Publish Selection записывает отмеченные элементы, а Publish All запрашивает всю коллекцию. В обоих случаях исключаются записи с включённым Don't Publish. Опубликованные позиции упорядочиваются по номеру изделия. Результат записывается в настроенный Publish HTML File; если путь не задан, программа запрашивает его. При наличии указанных изображений они копируются в сопутствующую папку медиафайлов рядом с HTML-файлом. На опубликованной странице отображаются карточки оборудования, изображения, названия, описания, статус бронирования и цены. Посетители могут искать по номеру изделия или описанию, выбирать период оплаты и сортировать по номеру, названию, описанию или цене по возрастанию и убыванию. Периоды: Daily, 3 Day, Weekly и Monthly. Символ валюты задаётся в Config. Если для выбранного периода нет цены, отличной от нуля, выводится Ask for price. Publishing записывает результат по выбранному HTML-пути и может заменить существующий HTML-файл. Перед публикацией проверьте место назначения и выбранные записи. При переносе сайта перемещайте сопутствующую папку медиафайлов вместе с HTML-файлом. [tab:fields] # Поля Fields содержит две вложенные вкладки: Tree View Fields и Editor Fields. Tree View Fields управляет столбцами List и их порядком. Для каждого столбца укажите имя поля, подпись, ширину, выравнивание и при необходимости метаданные Index или Unique. Add / Apply создаёт либо обновляет определение, Remove удаляет его из настроенного списка, Up и Down меняют порядок. Изменение списка определений перестраивает отображаемый List. Editor Fields управляет формой ввода записи. Определение поля содержит имя, подпись, тип, число строк, длину и метаданные Index и Unique. Поддерживаются коды типов 1 Short, 2 Long, 3 Text, 4 Integer, 5 Money, 6 Boolean, 7 Price Type и 8 Media. Многострочный текст, флажки и выбор тарифного периода отображаются в зависимости от типа поля. Для управления определениями и порядком используйте Add / Apply, Remove, Up и Down. Определения сохраняются в rental_catalog.json. Изменение или удаление поля из интерфейса само по себе не удаляет его из существующих документов MongoDB. При подключении к коллекции приложение также пытается создать уникальный индекс для part_number. Проверьте имеющиеся данные перед изменением ключевых полей и их определений. Документы MongoDB и реальные медиафайлы существуют отдельно от файла конфигурации. Перед импортом изображений или документов необходимо настроить Media Directory. 列表 List 显示来自已配置 MongoDB 数据库和集合的设备记录。Search 可按零件编号、简称、长描述和详细描述进行不区分大小写的搜索。New 在 Editor 中打开新记录，Refresh 重新加载当前结果。选择列表中的记录后，其详细信息会加载到 Editor。 默认列为 Part、Name、Qty、3 Day、Weekly、Monthly、Book 和 Don't Publish。Fields 选项卡用于设置列名、宽度、对齐方式和顺序。Config 中的 Page Size 限制显示的匹配记录数量；底部状态栏显示已加载数量和匹配总数。 [tab:editor] # 编辑器 Editor 用于创建和更新设备记录。Search 将输入的文本传递给 List。New 清空表单、生成候选零件编号、将数量设为 1，并默认选择三天租金。Add 向 MongoDB 插入新记录。Update 修改选中的记录；使用之前须先在 List 中选中一项。 每个零件编号必须由恰好两个字母和后续两个数字组成，例如 AB12，并且必须唯一。默认表单包含 Part Number、Short Name、Long Description、Detailed Description、Quantity、Daily Price、3 Day Price、Weekly Price、Monthly Price、Default Price、Don't Publish、Book、Primary Image 和 Document。金额以数值存储，数量以整数存储，两个标志以布尔值存储。Default Price 可选择每日、三天、每周或每月租期。Fields 控制 Editor 中显示的输入项。 Media 区域预览主图片。Pick Image 将文件系统中的图片复制到指定的 Media Directory。安装 Pillow 后，Paste Image 可以从剪贴板导入图片；安装 tkinterdnd2 后，可以将图片拖入预览区域。Pick Document 将选中的文件复制到 Media Directory，并把文件名填入 Document 字段。导入文件的名称包含零件编号；如有重名，会添加数字后缀以避免覆盖现有文件。图片以独立文件保存，MongoDB 记录仅通过文件名引用图片。使用 Add 或 Update 保存记录更改和媒体引用。 [tab:publishing] #
